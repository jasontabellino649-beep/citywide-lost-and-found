Citywide Lost & Found Management System (Java Swing)

HOW TO RUN (JDK 11 or newer)
  1. Open a terminal inside this folder.
  2. Compile:  javac *.java
  3. Run:      java LostFoundSystem

DEMO ACCOUNTS
  admin / admin123   (Administrator)
  user  / user123    (Citizen)
  maria / maria123   (Citizen)

Data is saved automatically to lostfound.dat in the folder you run from.
Delete that file to reset to the sample data.
